# E-Commerce Clothing System

A full stack e-commerce platform built with Spring Boot and Vue.

## Tech Stack

Backend
- Spring Boot
- Spring Security
- JWT
- MySQL
- Maven

Frontend
- Vue.js
- Bootstrap
- Axios

External APIs
- Razorpay Payment Gateway
- Google Maps API
- SMTP Email Integration

## Features

Customer
- Product browsing
- Wishlist
- Cart
- Checkout
- Razorpay payment
- Order tracking

Admin
- Category management
- Product management
- Inventory reports
- Delivery assignment

Delivery
- Assigned orders
- Google Maps navigation
- Delivery status updates
